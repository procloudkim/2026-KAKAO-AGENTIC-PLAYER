# concept/family-experience-mcp

상태: 1순위 추천

## 제품 약속

부모가 채팅에서 한 번 물으면, 바로 행동할 수 있는 아이 맞춤 체험 후보 3개를 받습니다.

## 대상 사용자

신생아, 영아, 유아, 미취학, 초등학생 아이에게 맞는 체험/행사를 찾는 부모와 보호자.

## 대표 상호작용

```text
User: 이번 토요일 서울에서 4살 아이랑 갈 만한 실내 체험 3개만 골라줘.
MCP: 후보 3개 + 나이 적합 이유 + 실내/실외 + 비용 + 예약/문의 링크 + 부모 체크사항.
```

## 첫 범위

- 지역: 서울 우선, 전국 확장은 이후.
- 나이: 아이 한 명의 나이 또는 학령 단계.
- 시간: 오늘, 주말, 특정 날짜 범위.
- 출력: 긴 행사 목록이 아니라 Top 3.

## 중단 규칙

행사 record가 날짜, 장소, 나이/대상 또는 프로그램 단서, 연락처/홈페이지, 출처 신선도를 제공하지 못하면 중단하거나 범위를 좁힙니다.
