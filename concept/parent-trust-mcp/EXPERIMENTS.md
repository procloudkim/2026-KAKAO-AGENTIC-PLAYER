# Experiments

## First MVP Experiment

Can one MCP response turn a baby-product concern into a safe evidence-lane parent action card without overclaiming?

## Fixed Variables

- No numeric safety score
- Trust Ledger required
- evidence completeness required
- official source lanes first

## Controllable Variables

- source lane coverage
- product category
- jurisdiction
- static demo vs live official lookup

## Promotion Rule

Promote when:

- missing identity path is useful
- conflict path keeps claims separated
- parent action card is concise
- medical/safety overclaim check passes

## Stop Rule

Stop if official source matching cannot be made reliable enough for a public PlayMCP demo before the review target.
