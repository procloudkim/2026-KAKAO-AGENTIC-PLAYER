문제와 가치

사용자 문제

검색은 많지만 판단은 부모 몫

부모는 포털, 지도, 기관 페이지를 오가며 날짜, 장소, 연령, 비용, 예약 여부를 직접 대조해야 합니다.

MCP 가치

채팅 한 문장을 action card로 변환

“이번 주말 4살 실내 체험”처럼 말하면 후보, 근거, 확인사항, 다음 행동을 한 번에 패키징합니다.

심사 포인트

편의성보다 신뢰 경계 우선

출처가 말하지 않는 최신성, 예약 가능, 운영 중, 아이 적합성은 약속하지 않고 확인 필요로 분리합니다.

기능별 목적

기능 목적 사용자에게 주는 결과 제출 전 경계
Loose prompt parsing 부모의 자연어 조건을 위치, 날짜, 아이 나이/단계, 실내외 조건으로 정리 채팅 그대로 입력해도 구조화된 검색 조건으로 처리 아이 나이 또는 단계가 없으면 한국어 clarification 반환
Candidate ranking 출처 기반 후보를 최대 3개로 압축 반복 검색 대신 비교 가능한 후보 목록 수신 후보 없음이면 fabricated match 없이 조건 완화 제안
Parent action card 방문 전 판단에 필요한 핵심 필드를 한 카드로 묶기 날짜, 장소, 주소, 비용, 출처, 확인 시점, 다음 행동 확인 예약/운영/적합성은 source field 없으면 확인 필요로 표기
Official-source ETL 공식 API/표준데이터를 정규화하고 캐시로 공급 채팅 요청마다 외부 API를 팬아웃하지 않는 안정적 응답 live proof는 source/key별 smoke 결과가 있을 때만 주장
Claim and secret guard 과장 주장과 키 노출을 제출 전 차단 심사/운영 문서에 raw key, keyed URL, unsupported claim 방지 scan:secrets, scan:sources, scan:claims 통과 필요

Tool Contract and Readiness

Toolfind_family_experiences
InputLoose prompt 또는 구조화 입력: location, date_range, child_age 또는 child_stage
Required selectorchild_age 또는 child_stage 중 하나. 없으면 한국어 clarification
Outputok=true이면 최대 3개 candidate action cards. ok=false이면 no-result, invalid-input, source/config failure
Card fieldstitle, date_time, venue, address, age_fit_label, fee_text, source_name, source_url, retrieved_at, warnings, parent_check, next_action
Ranking basisdate overlap, location relevance, child selector match, age-fit label, indoor/outdoor preference, source confidence, source authority, freshness, and field completeness.
Temporary/private readylocal tests, scans, golden fixtures, one public tool metadata, and operator copy are prepared for private PlayMCP smoke.
Not yet public-readyKakaoCloud PlayMCP-in-KC HTTPS deployment, PlayMCP endpoint update, final review request, public switch, contest submission, and representative image remain human decisions.
Endpoint evidencePath contract is `/mcp`; organizer endpoint pattern is `https://mcp-name.playmcp-endpoint.kakaocloud.io/mcp`; actual deployed endpoint is not assigned in this artifact.
Host secret boundaryHOST_REQUIREMENTS_SOT.md records the PlayMCP-in-KC secret strategy boundary. The final host secret strategy is a human decision before deployment.
Cache freshnessETL cache uses TTL metadata. Current safe default is 24 hours; stale or missing cache must be regenerated before relying on cache-first responses.
Age-fit basisage_fit_label must say source-stated, inferred, or unknown. It is evidence labeling, not a child-safety certificate.

Golden example: “이번 주말 4살 실내 체험 찾아줘” should return up to 3 cards with source, freshness, parent check, and next action. Missing age should return a Korean clarification instead of a raw SDK validation error.
