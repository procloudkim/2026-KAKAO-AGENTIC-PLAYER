문제와 가치

사용자 문제

검색은 많지만 판단은 부모 몫

부모는 포털, 지도, 기관 페이지를 오가며 날짜, 장소, 연령, 비용, 예약 여부를 직접 대조해야 합니다.

MCP 가치

채팅 한 문장을 action card로 변환

명시적 지역, 날짜, 아이 선택자를 모두 말하면 후보, 근거, 확인사항, 다음 행동을 한 번에 패키징합니다. 운영 starter는 PLAYMCP_TEMP_REGISTRATION.md가 소유합니다.

심사 포인트

편의성보다 신뢰 경계 우선

출처가 말하지 않는 최신성, 예약 가능, 운영 중, 아이 적합성은 약속하지 않고 확인 필요로 분리합니다.

Tool Contract and Readiness

Toolfind_family_experiences
Input자연어 또는 구조화 입력. location, date_range, 그리고 child_age/child_stage 중 정확히 하나가 필수
Missing/conflicting inputsilent default/날짜 확장 없이 typed invalid_input, exact missing_fields, source access 0
Outputok=true이면 최대 3개 candidate action cards. ok=false이면 no-result, invalid-input, source/config failure
Card fieldstitle, date_time, venue, address, age_fit_label, fee_text, source_name, source_url, retrieved_at, warnings, parent_check, next_action
Ranking basisdate overlap, location relevance, child selector match, source-supported age-fit label, source confidence, freshness, and field completeness.
Local package stateLocal artifacts target private PlayMCP smoke. Actual PlayMCP temporary registration and console smoke are NOT CLAIMED here.
Not yet public-readyKakaoCloud PlayMCP-in-KC HTTPS deployment, PlayMCP endpoint update, final review request, public switch, contest submission, and representative image remain human decisions.
Endpoint evidenceSee HOST_REQUIREMENTS_SOT.md. Actual deployed endpoint is not assigned in this artifact.
Host secret boundaryThe serving image uses only the gated bundled cache and needs no provider key. KTO credentials remain in the external ETL environment and are never pasted into PlayMCP or baked into the image.
Cache freshnessRuntime default is 24 hours and fails closed. Source-specific refresh cadence is operational metadata and does not silently override that TTL.
Container contractRepository-root linux/amd64 build, non-root node user, direct node PID 1, and static bundled cache.
Public diagnosticsHealth, error, and log surfaces redact paths, provider URLs, commands, credentials, stack traces, and deployment topology.
Age-fit basisage_fit_label must say source-stated, inferred, or unknown. It is evidence labeling, not a child-safety certificate.

The exact three production starters are canonical in PLAYMCP_TEMP_REGISTRATION.md and are not duplicated here. Missing location/date/child selector returns typed invalid_input with exact missing_fields and zero source access.
