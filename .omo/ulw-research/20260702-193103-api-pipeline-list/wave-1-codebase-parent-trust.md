# Wave 1 Codebase Digest: Parent Trust / Baby Product Safety

## Key Findings
- Existing harness already defines a strong official-source hierarchy and Trust Ledger boundary.
- Korean first lanes: SafetyKorea/KATS/KC, Food Safety Korea/MFDS, MFDS open-data recall APIs, Imported Food Information Maru, and KIPS.
- Global supporting lanes: CPSC recalls, SaferProducts.gov reports, eCFR/CPSC rule context, FDA/AAP/CDC/NIEHS guidance.
- Product identity intake is mandatory before lookup: model, SKU, certification number, batch/lot/date code, barcode, jurisdiction, import/seller context.
- Recall absence cannot be converted into a safe verdict.
